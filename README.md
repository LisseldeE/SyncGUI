# SyncGUI

一个简洁高效的本地与移动介质双向文件同步工具。

## 功能特性

### 核心功能

- **双向同步** - 支持本地与移动介质之间的双向文件同步
- **智能差异检测** - 自动识别新增、修改、冲突文件
- **目录级别同步** - 可配置特定目录按整体同步，减少重复操作
- **空目录同步** - 正确处理空目录及其目录结构
- **符号链接支持** - 完整支持符号链接的识别与同步
- **文件属性同步** - 同步文件的只读、隐藏、系统等属性

### 同步策略

| 状态 | 说明 |
|------|------|
| 一端独有 | 弹窗选择同步到另一端或删除 |
| 内容冲突 | 弹窗选择保留哪一端版本 |
| 时间差异 | 弹窗选择覆盖方向 |
| 目录同步 | 按配置规则整体同步 |

### 配置选项

```json
{
  "source_dir": "本地路径",
  "target_dir": "移动介质路径",
  "ignore_rules": [
    "SyncGUI/",
    "**/.git/"
  ],
  "sync_rules": [
    "Python/",
    "Servers/"
  ]
}
```

#### 忽略规则语法

| 规则 | 匹配范围 |
|------|----------|
| `目录名/` | 仅匹配根目录下的指定目录 |
| `**/目录名/` | 匹配任意位置的指定目录 |
| `.扩展名` | 匹配所有指定扩展名的文件 |

#### 同步规则

配置 `sync_rules` 后，指定目录下的第一级子目录将按整体同步，减少逐文件询问。

## 使用方法

1. 修改 `config.json` 配置同步路径
2. 运行 `SyncGUI.exe` 或 `python main.py`
3. 点击"扫描"检测差异
4. 根据弹窗提示选择同步方向
5. 点击"同步"执行操作

## 界面预览

- 主界面显示扫描进度与差异统计
- 弹窗统一样式，操作简洁直观
- 支持查看详细文件列表

## 技术实现

- Python + PyQt5 图形界面
- Windows API 高效文件复制
- MD5 哈希内容比对
- 进度回调节流优化

## 系统要求

- Windows 10/11
- Python 3.8+ (源码运行)
