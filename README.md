# SyncGUI

一个简洁高效的本地与移动介质双向文件同步工具。

## 功能特性

### 核心功能

- **双向同步** - 支持本地与移动介质之间的双向文件同步
- **智能差异检测** - 自动识别新增、修改、冲突文件
- **目录级别同步** - 可配置特定目录按整体同步，减少重复操作
- **空目录同步** - 正确处理空目录及其目录结构
- **符号链接支持** - 完整支持符号链接的识别与同步
- **文件属性同步** - 同步文件的只读、隐藏、系统等属性

### 同步策略

| 状态 | 说明 |
|------|------|
| 一端独有 | 弹窗选择同步到另一端或删除 |
| 内容冲突 | 弹窗选择保留哪一端版本 |
| 时间差异 | 弹窗选择覆盖方向 |
| 目录同步 | 按配置规则整体同步 |

### 配置选项

配置文件 `config.json` 会自动保存用户的设置，无需手动修改：

```json
{
  "wintogo_dir": "移动介质路径",
  "local_dir": "本地路径",
  "ignore_rules": [
    "SyncGUI/",
    "**/.git/"
  ],
  "sync_rules": [
    "Python/",
    "Servers/"
  ],
  "language": "zh",
  "sync_mode": "default"
}
```

#### 配置字段说明

| 字段 | 说明 |
|------|------|
| `wintogo_dir` | 移动介质目录路径 |
| `local_dir` | 本地目录路径 |
| `ignore_rules` | 忽略规则列表 |
| `sync_rules` | 同步规则列表 |
| `language` | 界面语言 (`zh` 中文 / `en` 英文) |
| `sync_mode` | 同步模式 (`default` 默认 / `newest` 最新优先) |

#### 忽略规则语法

| 规则 | 匹配范围 |
|------|----------|
| `目录名/` | 仅匹配根目录下的指定目录 |
| `**/目录名/` | 匹配任意位置的指定目录 |
| `.扩展名` | 匹配所有指定扩展名的文件 |

#### 同步规则

配置 `sync_rules` 后，指定目录下的第一级子目录将按整体同步，减少逐文件询问。

## 使用方法

1. 运行 `SyncGUI.exe` 或 `python main.py`
2. 选择移动介质目录和本地目录
3. 点击"扫描差异"检测文件差异
4. 根据弹窗提示选择同步方向（可点击"取消本次同步"终止）
5. 点击"执行同步"执行操作

### 同步模式

- **默认模式** - 对每个差异文件弹窗询问同步方向
- **最新优先** - 自动选择较新版本同步，减少弹窗询问

## 界面预览

- 主界面显示扫描进度与差异统计
- 弹窗统一样式，操作简洁直观
- 支持查看详细文件列表
- 支持中英文界面切换（点击语言按钮即可）
- 所有设置自动保存，下次启动自动恢复

## 技术实现

- Python + PyQt5 图形界面
- Windows API 高效文件复制
- MD5 哈希内容比对
- 进度回调节流优化

## 系统要求

- Windows 10/11
- Python 3.8+ (源码运行)
